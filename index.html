01 / orientation

先知道自己在走哪条路

CSP 的得分来自稳定完成前几题，再逐步扩展到中档题。路线按照“先拿稳，再变强”的顺序排列。

PHASE 01

建立工具感

熟悉 C++、STL、输入输出和复杂度，写出不容易崩的基础代码。

看 C++ 资源 ↗
PHASE 02

覆盖高频模型

模拟、搜索、贪心、二分、图论和 DP，形成题型到算法的映射。

看算法资源 ↗
PHASE 03

练出比赛节奏

用历年题做完整训练，学会拿部分分、切换题目和留出调试时间。

看真题入口 ↗
PHASE 04

收口与上场

整理模板、错题和考场清单，最后一周只做校准，不再无限扩展知识点。

看考场策略 ↗

02 / twelve-week plan

每周只抓一个主线

完成一周后勾选它，进度会自动保存在当前浏览器。不要追求“看完”，要追求“能独立写出来”。

0 / 12 周
W01

C++ 与 STL

把常用容器和算法写到不需要查文档。

  • 输入输出、函数、引用
  • vector / map / set / queue
W02

复杂度与基础技巧

能从数据范围反推可行算法。

  • 排序、枚举、前缀和
  • 差分、二分、双指针
W03

模拟与贪心

训练长题面下的状态管理与边界意识。

  • 时间线模拟、计数模拟
  • 局部最优与排序贪心
W04

搜索与剪枝

建立从状态、转移到剪枝的思考顺序。

  • DFS / BFS / 回溯
  • 状态表示与可行性判断
W05

图论基础

解决连通性、距离、依赖关系问题。

  • 并查集、拓扑排序
  • BFS、Dijkstra、MST
W06

线性 DP

学会定义状态，而不是背答案。

  • 背包、LIS、路径 DP
  • 状态转移与初始化
W07

树与区间

补齐中档题常见的数据结构模型。

  • 树遍历、树上 DP
  • 树状数组、线段树
W08

数学与字符串

处理计数、模运算和基础匹配问题。

  • GCD、筛法、快速幂
  • Trie、KMP、字符串哈希
W09

近年真题 1

第一次整套训练，重点观察时间分配。

  • 连续 4 小时完成一套
  • 统计每题得分与耗时
W10

近年真题 2

把失分点变成可执行的检查项。

  • 错题重做与对拍
  • 补缺一项薄弱算法
W11

全真模拟

训练切题、提交和调试节奏。

  • 至少两次完整模拟
  • 整理自己的代码模板
W12

收口与上场

降低波动，准备证件和考试环境。

  • 只复习错题与模板
  • 确认当期官方通知

03 / daily loop

今天照着做，别等状态

每天 2-3 小时即可。关键是固定动作：输入、独立完成、复盘、记录。

01

热身：复写一个模板

不看资料写出快速输入、排序、二分或 BFS 模板，并解释每一行。

20 MIN
02

主练：独立做一道题

先读数据范围，写出暴力，再决定是否优化。卡住 40 分钟就先换题。

90 MIN
03

复盘：写下一个错误

记录错误类别、触发条件和下一次检查动作，不要只保存题解链接。

25 MIN
04

收尾：补一道同型题

从题单中再做一道同模型题，让算法从“看懂”变成“会用”。

30 MIN

今天的验收标准

结束时不问“我看了多少视频”，只问下面三件事：

  1. 我能说出这道题的状态和复杂度吗？
  2. 我能不看题解重写关键代码吗？
  3. 我知道自己下一次会检查什么吗？

05 / exam room

最后把波动降下来

考场上最值钱的是可控的节奏。先拿确定分，再用剩余时间换更高分。

阶段动作自检问题
开始 15 分钟浏览所有题，标记确定题、部分分题和暂时跳过题。数据范围是什么？哪题最适合先拿分？
中段 2 小时完成基础题，提交能拿部分分的版本，及时切换。我是否在一题上消耗过久？
结束前 30 分钟检查溢出、下标、清空、复杂度和输出格式。最小值、最大值、重复值能过吗？
报名、考点、考试语言和入场要求可能随场次调整。训练最后一周务必回到 CCF-CSP 官方网站，逐项核对当期通知。
